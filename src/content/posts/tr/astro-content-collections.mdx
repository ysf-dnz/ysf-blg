Bir blogda en sinsi hata türü, sessizce bozulan içeriktir: eksik tarih,
yanlış kategori, kırık kapak görseli. Astro'nun content layer API'si bu
sınıfı derleme zamanında yok ediyor.

## Şema tanımı

Koleksiyon şeması tek yerde durur ve her yazının frontmatter'ı buradan geçer:

```ts title="content.config.ts"
import { defineCollection, z } from "astro:content";
import { glob } from "astro/loaders";

const posts = defineCollection({
  loader: glob({ pattern: "**/*.mdx", base: "./src/content/posts" }),
  schema: z.object({
    title: z.string().min(1),
    pubDate: z.coerce.date(), // [!code highlight]
    category: z.enum(["ai", "yazilim", "girisimcilik"]),
    draft: z.boolean().default(false),
  }),
});
```

<Callout type="ipucu" baslik="Neden z.coerce.date?">
  YAML'da tarihler bazen string, bazen Date olarak parse edilir.
  `z.coerce.date()` iki durumu da normalize eder.
</Callout>

## Sorgulama

Yazıları çekerken filtre fonksiyonu draft'ları üretimde gizler:

```ts title="src/lib/posts.ts"
const posts = await getCollection("posts", ({ data }) => {
  return !(data.draft && import.meta.env.PROD);
});
```
